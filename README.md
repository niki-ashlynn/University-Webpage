# 🎓 British University College Website

### University Website & Student Management System

A university website developed as part of the **COS108 coursework**, featuring student registration, club information, university events, administrator login, and student record management.

The project demonstrates frontend and backend web development using HTML, CSS, JavaScript, PHP, and MySQL.

## 📌 Project Overview

The British University College Website was designed to provide a centralised platform for students to access university information, explore available clubs, view activities and events, and register for student activities.

The website also includes an administrative dashboard for managing student records.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML | Website structure and content |
| CSS | Website styling and layout |
| JavaScript | Form validation and page navigation |
| PHP | Server-side processing and student management |
| MySQL | Student registration data storage |

## ✨ Key Features

### 1. University Homepage
- Displays university information and academic opportunities.
- Provides navigation to different website sections.
- Includes information about the university's programmes and services.

### 2. Student Registration
- Allows students to enter their student ID and password.
- Provides a club selection field.
- Processes registration using PHP.
- Stores student registration credentials in a MySQL database.

### 3. Clubs & Events
- Displays available university clubs.
- Provides information about student activities and events.
- Includes a club registration interface.

### 4. Admin Dashboard
- Provides an administrative interface for managing student records.
- Displays registered students in a table.
- Supports adding, editing, deleting and searching student records.

### 5. Form Validation
- Uses JavaScript to validate required form fields.
- Checks that passwords meet minimum length requirements.
- Uses PHP for server-side database operations.

## ⚙️ How It Works

**Student Interface**

1. Users visit the university homepage.
2. They navigate through university information, clubs and events.
3. Students can access the registration form.
4. Registration information is processed using PHP.

**Administrator Interface**

1. The administrator accesses the login page.
2. The dashboard provides access to student management.
3. Student records can be viewed, added, edited, deleted or searched.
4. Database operations are performed using PHP and MySQL.
